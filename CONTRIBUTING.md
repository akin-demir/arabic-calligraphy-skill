# Contributing

Use a feature branch and Conventional Commits. Install native dependencies and `python -m pip install '.[dev]'`. Run `python scripts/check_project.py`, `PYTHONPATH=src python scripts/verify_accuracy.py` and regenerate the gallery when rendering changes. Keep real milestones; do not squash the initial engineering history.

Font contributions need an exact source/version/hash, full license/notice, embedding permissions, coverage and shaping tests. Styles need reliable historical references and a separate implementation/capability classification. No reference-only style may silently select an unrelated font. Provisional historical notes welcome corrections with specific museum, scholarly or primary sources.

Expert review evidence should name the reviewer with consent, identify qualifications, date, exact output hash, style/school and the reviewed scope. Record criticisms as well as acceptance. Automated similarity or an LLM opinion cannot replace that review. Translations, Unicode edge cases, layouts, technical reviews and corrections are welcome. Include source and output files in bug reports only when you have permission to share them.
