# v0.1.0-rc.1 — first experimental release candidate

This candidate is ready for you to try locally. It is a prerelease, not a stable Arabic publishing system. The repository remains private.

## Included

- Portable Agent Skill and twenty introductory tradition references.
- Three working font-based typography styles: Naskh, modern Kufic and Nastaliq Urdu. All are classified Approximate; none is certified classical calligraphy.
- Offline Pango/HarfBuzz/Cairo PNG, outlined SVG and native embedded-font PDF exports.
- CLI/Python API, posters, transparent wordmarks, certificates and paginated new documents.
- Four bundled licensed Noto fonts, coverage/overflow checks, real gallery and bilingual documentation.
- 374 automated tests, dependency audit, accuracy evidence and checksummed source/wheel artifacts.

## Known PDF limitation — PDF-001

PDFs render and embed fonts, but raw Arabic extraction may reorder letters, diacritics or mixed-language runs. Search and copy/paste vary by reader. ActualText mappings preserve logical source text but do not yet establish lossless extraction. Use PNG/SVG for artwork and keep the original UTF-8 source. Do not rely on these PDFs for lossless text extraction yet. This issue blocks a stable release, but the owner explicitly requested RC1 for testing with it documented.

## Try RC1

On Debian/Ubuntu Linux, install native dependencies, then clone the exact tag:

```bash
sudo apt-get install libpango-1.0-0 libpangocairo-1.0-0 libcairo2 libfontconfig1 libharfbuzz0b
git clone --branch v0.1.0-rc.1 https://github.com/akin-demir/arabic-calligraphy-skill.git
cd arabic-calligraphy-skill
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
arabic-calligraphy render --text "العلم نور" --style naskh --output artwork.svg
arabic-calligraphy poster --text "اللغة العربية" --style kufic --output poster.png
arabic-calligraphy certificate --recipient "أحمد محمد" --body "تقديراً للجهود المتميزة" --output certificate.pdf
arabic-calligraphy document --input examples/documents/report.md --output report.pdf
```

Private repository access requires your GitHub authentication. Alternatively download the wheel, install the same native libraries, and use `python -m pip install ./arabic_calligraphy_skill-0.1.0rc1-py3-none-any.whl`. Python dependencies may be downloaded during installation; rendering itself is offline. Verify downloaded assets with `sha256sum -c SHA256SUMS` after placing all assets together.

To try agent discovery from the cloned tag: `npx skills add . --skill arabic-calligraphy-skill`. Node.js 22.20+ and separate Python/native setup are required. End-to-end agent execution remains a planned RC2 validation; do not assume installing the metadata installs the renderer dependencies.
