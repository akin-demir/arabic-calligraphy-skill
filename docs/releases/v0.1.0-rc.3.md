# v0.1.0-rc.3 — manual Square Kufic studies

RC3 adds a separate manual Square Kufic grid workflow to the existing Naskh,
modern Kufi, Nastaliq and limited Diwani font workflows. These four remain
font-based approximations. No independent calligrapher certification is claimed.

## New in RC3

- `arabic-calligraphy grid` inspects editable, labeled cells and exports PNG/SVG.
- An original `الله` study includes JSON, PNG and SVG, with exact Unicode source
  spans for letter-by-letter review. SVG metadata retains the source map.
- Checks refuse solid 2×2 blocks and corner-only contacts, report empty patches
  and odd dimensions, and enforce bounded input/output sizes.
- The skill distinguishes manual geometry from modern Kufi font typography.
- 482 automated checks pass, including source-map integrity, cell-pixel export,
  refusal behavior, resource limits and existing typography regression checks.

This is a basic letter study, **not a packed, interlocking emblem**. Arbitrary-text
Square Kufic conversion, automatic word turns and a reviewed contextual alphabet
remain unfinished. `render --style square-kufic` still refuses unsupported requests.
The separate Thuluth experiment and README redesign are not included in RC3.

## Try it

Download `arabic-calligraphy-skill-rc3.zip`, extract it, and install the package
after following `docs/installation.md` for Python and native Pango/Cairo dependencies.
Skill upload alone does not install the runtime. Alternatively install the wheel
and obtain the editable examples from `square-kufic-study.zip`.

```bash
python -m pip install .
arabic-calligraphy grid --input examples/square-kufic/allah-study.json
arabic-calligraphy grid --input examples/square-kufic/allah-study.json --output study.svg
arabic-calligraphy grid --input examples/square-kufic/allah-study.json --output study.png
```

Inspect the actual image against its source map. Geometry checks cannot validate
Arabic spelling, joining, reading order, recognizable letterforms or authenticity.
Keep the JSON alongside the artwork. The new grid workflow supports PNG/SVG only.

Existing Diwani restrictions remain: unvocalized PNG/SVG only; PDF and combining
marks are refused. PDF-001 also remains: Arabic extraction/search/copy in the
existing PDF workflows depends on the reader and is not lossless. RC3 is an
experimental prerelease for testing with these disclosed limitations, not a stable
release. RC1 and RC2 remain unchanged.

## Assets and provenance

The skill ZIP, wheel, source distribution, gallery, grid-study ZIP, accuracy and
font-license evidence, release manifest and SHA-256 checksums are built from the
same tagged main commit. Verify downloaded assets with `sha256sum -c SHA256SUMS`.
No new third-party font or chart artwork is bundled in this candidate.
