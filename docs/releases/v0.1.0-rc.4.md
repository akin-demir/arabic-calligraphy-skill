# v0.1.0-rc.4 — Square Kufic README artwork

RC4 adds the actual Square Kufic README composition to the RC3 manual-grid
workflow. Both READMEs show a teal-and-gold motif built from four copies of the
editable `الله` study. Physical cells rotate clockwise by 0°, 90°, 180° and 270°;
the source remains `الله الله الله الله`, with a separate source span for every
letter. No filler strokes, mirrored text or third-party chart artwork are added.

## New in this candidate

- A reproducible 1600×880 PNG and outlined SVG banner, generated by Cairo from
  the actual labeled cells and bundled fonts, with source metadata retained.
- `examples/square-kufic/readme-rosette.json` exposes the editable 19×19 motif.
- The normal gallery generator rebuilds the banner. English and Arabic READMEs
  link the preview, vector output, editable data and grid workflow.
- Superseded README work is closed and inactive branches are cleaned up with
  guards that preserve open PRs, changed heads and unmerged work.
- A prepared main-protection policy and accurate administration status replace
  stale setup notes. **Main remains unprotected**: GitHub requires public visibility
  or an eligible plan, and administrator access is unavailable in this session.

## Try the artwork

Extract `arabic-calligraphy-skill-rc4.zip`, install native dependencies as described
in `docs/installation.md`, then install the package from that directory:

```bash
python -m pip install .
arabic-calligraphy grid --input examples/square-kufic/readme-rosette.json --output motif.svg
arabic-calligraphy grid --input examples/square-kufic/readme-rosette.json --output motif.png
PYTHONPATH=src python scripts/generate_readme_hero.py
```

The standalone `square-kufic-study.zip` contains both editable grid studies. The
banner is also included in `gallery.zip` and the full source/skill archives.
Skill upload alone does not provide Python or native Pango/Cairo dependencies.

## Validation and limits

482 automated checks pass. Repository checks, full gallery generation, visual
inspection, geometry inspection and dependency audit run before publication.
Source, wheel, skill ZIP, examples, evidence and SHA-256 checksums are built from
the same tagged main commit. No previous tag or release is overwritten.

The motif is an original manual composition awaiting independent calligrapher
review. It does not establish arbitrary-text Square Kufic conversion, a packed
composition engine or historical authenticity. The four font workflows remain
Naskh, modern Kufi, Nastaliq and limited Diwani. The rejected Thuluth trial is closed and excluded from RC4.
Diwani still refuses PDF and combining marks. PDF-001 remains: Arabic extraction,
search and copy behavior is reader-dependent. This is an experimental prerelease,
and the stable-release gate remains blocked.
