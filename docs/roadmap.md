# Roadmap

0.1 candidate: three honest font-based styles, 20 introductory references, CLI/API, PNG/SVG/PDF, measured layouts, tests and real examples. Before release: resolve exact PDF extraction, validate remote CI/security and clean installation, test Skills CLI discovery, verify repository protections, and obtain maintainer approval.

0.5: integrate Aref Ruqaa after source/license/version audit; improve Nastaliq poetry layout; develop a dedicated, text-audited Square Kufic composition tool rather than pretending a generic font is sufficient; expand school-specific scholarship and independent reviews.

1.0: stable API, broader platform verification, expert-reviewed composition evidence and accessible PDF reading order. Optional future web playground: offline renderer in a constrained server process with input/resource limits. No online service is required for the initial release.
