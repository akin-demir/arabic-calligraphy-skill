# Typography review

Retain input Unicode and never reverse strings. Use Naskh for readable body text, modern Kufi for short display, and generous line height with Nastaliq. Inspect hamzas, dot distinctions, mark collisions, punctuation and mixed-language order. Font coverage is necessary but does not establish correct artistic composition. Do not add vocalization or change religious text without an explicit source and user intent. Match script references to period and school.
